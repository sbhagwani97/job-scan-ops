# Cover letter structure (guide for /job-scan:apply)

1. Opening (2 sentences): the role, the company, and one concrete reason this company in particular.
2. Evidence paragraph: 2-3 achievements from the CV that map directly to the top requirements of the posting. Use numbers that exist in the CV; never invent any.
3. Fit paragraph: address one gap honestly, if any, and how you would close it.
4. Close: availability, location/visa facts if relevant, one line call to action.

Rules: under 300 words, no clichés ("passionate", "team player"), plain text, match the posting's language.
